# Robô Aventureiro 🤖

Jogo de plataforma em HTML, CSS e JavaScript puro.

## Como jogar
1. Extraia os arquivos do ZIP.
2. Abra `index.html` no navegador (Chrome, Edge ou Firefox).
3. Clique em **Começar a jogar**.

## Controles
- `←` / `→` ou `A` / `D`: mover
- `Espaço`, `↑` ou `W`: pular
- `R`: reiniciar a fase
- Em celular, use os botões na tela.

## Objetivo
Colete moedas suficientes para ativar o portal de cada fase. Evite espinhos e inimigos. São 3 fases.

Não precisa instalar bibliotecas nem servidor. A fonte do Google é opcional; o jogo funciona com fontes locais se estiver sem internet.
